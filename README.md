# School & Organizational Management System
**Owner:** Hikmatulloh, M.Pd.I.
**Vision:** Dakwah Pendidikan dan Transformasi Digital.

## 🎯 Purpose
Repositori ini berfungsi sebagai pusat dokumentasi digital (Single Source of Truth) untuk SDN 1 Kucur, KKG PAI, dan KPRI Dian Dau.

## 📂 Directory Structure
- `01_SOP`: Standardisasi prosedur kerja untuk efisiensi staf.
- `02_POLICY`: Payung hukum kebijakan sekolah.
- `03_LAPORAN`: Jejak rekam kinerja dan finansial (Audit ready).
- `04_DASHBOARD`: Akses cepat ke data analitik (Looker Studio).

## 🛡️ Access Policy
- **Public:** Dokumen umum (SOP, Kebijakan).
- **Private:** Dokumen sensitif (Data keuangan, privasi siswa, personalia).
